# RaceDay System Architecture

## Overview
RaceDay is a full-stack web application built with:
- Frontend: MVC (Part 3)
- Backend: RESTful API (Part 2)
- Database: SQL Server
- Hosting: Azure (Part 3)
- Containerization: Docker (Part 3)

## Architecture Layers
1. **Presentation Layer** - MVC Web Application
2. **Business Logic Layer** - API Controllers
3. **Data Access Layer** - Entity Framework
4. **Database Layer** - SQL Server

## Security
- JWT Authentication
- Role-based Authorization
- HTTPS
- Password Hashing

## Deployment Strategy
- GitHub Actions for CI/CD
- Docker containers
- Azure Cloud deployment
